# Inventory Management System

A simple Inventory Management System built with Python using Object-Oriented Programming (OOP) concepts.

## Features

- Create and manage products
- Add stock
- Remove stock
- Check current quantity
- Get and update product price
- Electronics products with warranty
- Clothing products with size and brand
- Encapsulation
- Getter and Setter
- Inheritance
- Method Overriding
- Polymorphism
- `super()` usage

## OOP Concepts Used

- Classes & Objects
- Constructors
- `self`
- Instance Variables
- Private Variables
- Encapsulation
- Getter / Setter
- Inheritance
- `super()`
- Method Overriding
- Polymorphism

## Technologies

- Python
- Object-Oriented Programming (OOP)

## Project Purpose

This project was created to practice and strengthen Python OOP concepts through a simple real-world inventory management system.
